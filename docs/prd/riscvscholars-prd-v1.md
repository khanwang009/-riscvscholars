产品名称：`riscvscholars.org`  
版本：`v1.0`  
日期：`2026-04-20`

## 1. 产品概述
`riscvscholars.org` 是一个面向跨国 RISC-V 学术合作的入口平台。  
第一阶段以**海外 RISC-V 学术机构公开档案**为基础，通过**机构认领**与**中国实验室合作申请表单**，促成一批高质量的双边初次会谈。

它不是论文数据库，也不是学术社区，更不是正式项目管理系统。  
它的核心作用是：

- 让海外机构在中文合作语境中被准确理解
- 让中国实验室更快找到合适的海外合作对象
- 让合作从“浏览信息”进入“结构化申请与筛选”

---

## 2. 背景与机会
当前跨国 RISC-V 学术合作存在几个明显断点：

- 海外机构的公开资料分散，且对中国合作方不够友好
- 中国实验室难以快速判断哪些海外团队值得接触
- 双方缺少标准化、低摩擦的合作入口
- 你们团队有人懂芯片研发、产品策划、内容组织和技术转化，具备建立中立入口平台的条件

域名从 `RISC-V.team` 迁移到 `riscvscholars.org` 后，产品重心应从“团队连接”进一步收敛到：

**学术机构档案 + scholar-facing collaboration gateway**

---

## 3. 产品目标

### 3.1 第一阶段目标
- 建立一批高质量海外 RISC-V 学术机构档案
- 让海外机构可以认领并补充自己的合作信息
- 让中国实验室通过标准表单提交合作申请
- 由平台筛选后促成双边初次会谈

### 3.2 12个月目标
- 平台能稳定促成一批双边初次会谈
- 平台形成可持续更新的海外机构档案库
- 平台在中文 RISC-V 学术合作场景中形成初步可信度

---

## 4. 非目标
第一阶段明确不做：

- 不做正式项目管理系统
- 不做大而全的学术社区
- 不做论文数据库
- 不做企业 PoC 主平台
- 不做招生/招聘平台
- 不做复杂会员体系
- 不做强运营、强人工维护的撮合平台

---

## 5. 目标用户

### 5.1 第一优先用户
**海外 RISC-V 学术机构**
包括：
- 高校实验室
- 研究中心
- 开源硬件研究团队
- 与 RISC-V 紧密相关的开放研究平台

他们的核心需求：
- 被准确展示
- 被高质量中国团队发现
- 低成本表达合作意向
- 保留对合作入口的控制权

### 5.2 第二优先用户
**中国实验室 / 科研团队**
包括：
- 高校实验室
- 科研院所
- 国家事业单位相关研发团队

他们的核心需求：
- 快速找到匹配的海外机构
- 低成本判断合作方向
- 用结构化方式发起合作，而不是冷邮件乱投

---

## 6. 核心价值主张

### 对海外机构
- 我们先帮你建立高质量公开档案
- 你可以认领并补充合作偏好
- 平台先筛选中国申请，再决定是否推进会谈

### 对中国实验室
- 你可以系统浏览海外机构，不用自己碎片化搜索
- 你可以按研究方向和合作意图筛选对象
- 你可以通过标准合作表单发起申请，提高成功率

### 对平台自身
- 先以公开资料建档降低冷启动成本
- 再通过认领与申请机制形成持续更新和转化
- 用“标准表单 + 人工筛选”控制质量，而不是做纯开放通讯录

---

## 7. 核心成功指标

### 7.1 北极星前置指标
**留下可被联系或可被认领合作资料的海外机构数量**

### 7.2 辅助指标
- 海外机构档案页数量
- 被认领的机构页数量
- 机构补充合作意向的数量
- 中国实验室提交合作申请的数量
- 通过初筛的申请数量
- 被安排的双边初次会谈数量

---

## 8. 产品原则
- `Scholar-first`：优先服务海外学术机构的表达与控制权
- `Source-based`：所有机构档案必须基于公开资料
- `Structured, not noisy`：结构化档案优先，不做资讯堆砌
- `Low-ops by design`：产品机制必须适应低人工运营
- `Curated collaboration`：不是开放通讯录，而是筛选后的合作入口

---

## 9. 核心用户场景

### 场景 A：海外机构被平台收录
1. 平台基于公开资料建立海外实验室档案
2. 该档案对外可浏览
3. 海外机构后续可认领页面并补充资料
4. 平台标记该机构是否接受合作申请

### 场景 B：中国实验室寻找合作对象
1. 中国实验室进入平台浏览海外机构
2. 按方向、国家、合作类型筛选
3. 查看机构档案和合作偏好
4. 提交标准合作申请表单
5. 平台决定是否推进会谈

### 场景 C：海外机构认领页面
1. 海外机构点击 `Claim this profile`
2. 提交身份信息与补充材料
3. 平台审核
4. 通过后该机构可补充合作兴趣、 preferred contact path 等

### 场景 D：平台推进会谈
1. 平台收到中国实验室的合作申请
2. 判断匹配度和申请质量
3. 若合适，转发给海外机构或发起引荐
4. 促成初次线上会谈

## 15. 运营机制

### 第一阶段运营方式
- 平台先用公开资料建档
- 通过内容页和专题页建立可信度
- 邀请部分海外机构认领页面
- 中国实验室通过表单发起申请
- 平台低频人工筛选和推进

### 低运营原则
- 不做实时互动社区
- 不承诺高频人工匹配
- 只处理高质量申请
- 先小规模验证会谈链路

## 18. 风险与假设

### 关键假设
- 海外机构会接受“先被收录，再认领”
- 中国实验室愿意通过标准表单而非直接要联系方式
- 平台的筛选能提高合作质量
- 低频人工运营足以支撑第一阶段

### 主要风险
- 海外机构认领率偏低
- 中国实验室申请质量不稳定
- 平台被误解为纯目录站
- 人工筛选负担超出预期

---

## 19. 当前版本的关键决策
本 PRD v1 基于以下已确认前提：
- 核心定位：海外与中国实验室合作入口
- 首要结果：稳定促成一批双边初次会谈
- 第一阶段双边同时服务，但优先服务海外机构
- 第一阶段不做正式项目管理系统
- 默认机制：先填标准合作表单，再决定是否安排会谈
- 主建档路径：平台先用公开资料建档，后续邀请机构认领和补充
